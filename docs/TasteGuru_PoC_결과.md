## 1. 상품 URL 정보 추출

Worker가 상품 페이지 HTML을 받아 Open Graph 메타와 JSON-LD(구조화 데이터)를 읽는 방식. 브라우저 / 페이스북 / 카카오톡 / 트위터 4가지 User-Agent로 시도.

| 사이트 | 테스트 URL | 결과 | 가져온 정보 |
| --- | --- | --- | --- |
| 컬리 | /goods/5082274 | ✅ 4개 UA 모두 200 | `[비비고] 왕교자 만두 대용량 1.05kg`, 이미지, 11,480원, 브랜드 비비고 |
| 컬리 | /goods/5082275 | ✅ 4개 UA 모두 200 | `[비비고] 김치 왕교자 만두 대용량 1.05kg`, 이미지, 12,980원, 비비고 |
| 11번가 | /products/9203592919 | ✅ 200 | `비비고 수제든든한섬만두 768g`, 이미지, 9,900원, CJ |
| 쿠팡 | /vp/products/206820279, 9240522265 | ❌ 4개 UA 모두 403 | 없음 ("Access Denied") |
| 쿠팡 모바일 | m.coupang.com/vm/products/206820279 | ❌ 403 | 없음 |
| 스마트스토어 | smartstore.naver.com/cjthemarket | ❌ 429 / 로그인 페이지 | 없음 |

- 컬리는 페이지에 **JSON-LD Product** 정보가 있어 가격·브랜드까지 안정적으로 추출됨
- 응답 시간 약 0.25~2초

**결론**: 기존 판단 "일부 가능" 유지.
- **컬리·11번가**: URL 붙여넣기로 자동 입력 가능
- **쿠팡**: 서버에서 가져오기 불가 → 직접 입력, 또는 같은 제품의 컬리·11번가 URL 사용
- **스마트스토어**: 서버에서 가져오기 불가 → 직접 입력

> **정정 (2026-10-11)**: 구상 단계에서 기본 입력 경로로 잡았던 **네이버 쇼핑 검색 API는 2026-07-31에 종료**되었습니다(쇼핑·책·전문자료 검색은 대체 없이 종료, 블로그·뉴스·이미지 등 일반 검색은 NAVER API HUB로 이관되어 현재 한시적 무료). 입력 경로 재설계가 필요합니다.

## 3. D1·R2 응답 시간

| 항목 | 측정값 | 참고 |
| --- | --- | --- |
| D1 쓰기+읽기 | 약 370 ms | 측정 요청이 **미국(IAD)** 에서 실행되어 APAC DB까지 왕복한 값 |
| R2 쓰기+읽기+삭제 | 약 1.3~1.8 s | 위와 같음 (3회 왕복) |

이 테스트 환경이 미국에 있어서 느리게 나왔습니다. **한국에서 접속하면 서울(ICN) 근처에서 Worker가 실행되고 DB도 APAC에 있어 훨씬 짧을 것**으로 예상합니다. 키를 넣은 뒤 휴대폰으로 PoC 페이지를 열면 상태 영역에 실행 위치(colo)와 시간이 보입니다.

## 다음에 필요한 것: 구글 OAuth 키 발급

### A. 구글 OAuth 클라이언트

1. https://console.cloud.google.com → 새 프로젝트 `TasteGuru` 생성
2. **API 및 서비스 → OAuth 동의 화면**: 사용자 유형 **외부**, 앱 이름 `TasteGuru`, 지원 이메일 입력
   - 테스트 모드로 두면 **테스트 사용자로 등록한 계정(최대 100명)만** 로그인 가능 → 지인 10명이면 테스트 모드로도 충분하지만, 초대할 때마다 이메일 등록이 필요. 번거로우면 **게시(프로덕션)** 로 전환(이메일·프로필 같은 기본 범위만 쓰면 보통 별도 심사 없이 전환 가능)
3. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - 승인된 JavaScript 원본: `https://tasteguru.nogamenogain.com`
   - 승인된 리디렉션 URI: `https://tasteguru.nogamenogain.com/api/auth/callback/google`
4. **Client ID / Client Secret** 확인

### B. Cloudflare에 등록 (키 값은 채팅에 붙여넣지 마세요)

Cloudflare 대시보드 → **Workers & Pages → tasteguru-poc → Settings → Variables and Secrets → Add**

| 이름 | 종류 | 값 |
| --- | --- | --- |
| `GOOGLE_CLIENT_ID` | Secret | 구글 Client ID |
| `GOOGLE_CLIENT_SECRET` | Secret | 구글 Client Secret |
| `ADMIN_EMAIL` | Text | 관리자가 될 본인 구글 이메일 (다른 사람이 먼저 가입해 관리자가 되는 것 방지) |

등록 후 알려 주시면 구글 로그인을 최종 확인하고, 결과를 이 문서와 명세에 반영합니다.

## 참고: PoC 페이지 사용법

- 첫 화면에서 상태 확인, 구글 로그인, 초대 링크 생성, 네이버 검색, URL 추출을 시험할 수 있음
- 로그인 전에는 **PoC 키**를 입력해야 URL 추출이 동작 (키는 별도 전달)
- PoC가 끝나면 Worker·D1·R2를 삭제하거나 본 개발용으로 이름을 바꿔 재사용
