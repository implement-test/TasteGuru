# TasteGuru

- **현재 단계**: 개발

## ① 개요

- **한 줄 소개**: 소규모 그룹이 음식 평점을 저장 및 관리하는 웹 앱

**목적**

- 인터넷으로 다양한 음식을 시켜 먹는데 시간이 지나면 맛있었는지 맛없었는지 기억이 나지 않음
- 맛있다. 맛없다가 아닌 짜다, 달다, 맵다 등 세부적으로 평가를 저장하고 싶음

- **개발 이유**: 맞춤형, 취미

**이유 상세**

- 쇼핑몰의 리뷰는 너무 광고형 리뷰가 많아서 신뢰하기 어려움
- 특히 자극적인 맛을 좋아하는 사람들이 많아서 나와 잘 안맞는다고 느꼈음

- **사용자**: 소수 지인

## ② 개발 전 확인 필요

### 확인 항목

| 확인 내용 | 결과 | 설명 |
| --- | --- | --- |
| 쿠팡, 컬리 등 온라인 마켓에서 정보 가져오기 | 일부 가능 | PoC(2026-10-11) 결과: 컬리·11번가는 상품 URL에서 제품명·대표 이미지·가격·브랜드 자동 추출 성공(Open Graph·JSON-LD). 쿠팡은 PC·모바일, 4가지 User-Agent 모두 403 차단으로 불가. 네이버 스마트스토어 URL은 429 또는 로그인 페이지로 이동해 불가. 네이버 쇼핑 검색 API는 2026-07-31 종료되어 신규 발급 불가(대체 API 없음). 쿠팡 상품은 직접 입력 또는 다른 쇼핑몰 URL로 대체. 영양 정보는 대부분 상세페이지 이미지 안에 있어 자동 추출 불가 |
| 영양 정보 자동 입력 | 일부 가능 | 식약처 식품영양성분 DB(K-FIND, 공공데이터포털 Open API)로 가공식품 영양성분 조회 가능. 쇼핑몰 제품명과 DB 제품명이 정확히 일치하지 않아 자동 매칭은 불확실하므로 사용자가 검색 결과에서 직접 선택하는 방식 필요. MVP 이후 단계로 미룸 |
| 무료 호스팅·DB로 상시 운영 | 가능 | Cloudflare Workers Paid(사용 중) 포함량 안에서 운영. Supabase 무료 플랜의 7일 비활성 일시정지 문제 없음. D1 Time Travel로 최근 30일 시점 복구 가능 |
| Supabase 대신 Cloudflare만으로 개발 | 가능 | DB는 D1, 사진은 R2, 로그인은 Better Auth(Google), 호스팅은 Workers Static Assets, 예약 작업은 Cron Triggers로 대체. 2026-10-01~10-11 기존 사용량은 요청 약 1%, CPU 약 6%, R2 저장 약 40%(월 포함량 대비)이며 TasteGuru 추가 후에도 포함량 안으로 추가 비용 없음. R2 버킷 sf6-repository-opennext-cache가 하루 약 0.17GB씩 증가 중이라 계정 R2 무료 10GB 초과 가능성 있음 |
| API를 통한 상품 정보 입력 | 기타 | 네이버 쇼핑 검색 API 종료로 상품명·가격 검색 API 없음. NAVER API HUB 이미지 검색으로 사진·이름 후보를 찾는 "상품 검색" 탭으로 구현(v0.2.1). 가격·브랜드는 직접 입력 |

## ③ 기능

### 핵심 기능 (MVP)

- [ ] 사용자 별로 음식에 평가를 할 수 있음
  - 맛에는 맵다, 달다, 짜다 등 다양한 항목이 있으며 일부만 점수를 매길 수도 있음
    - 맛 항목 점수는 강도(0~5)
    - 기본 맛 항목: 단맛, 짠맛, 매운맛, 신맛, 쓴맛, 감칠맛, 느끼함, 식감
    - 맛 항목 추가·수정은 관리자만 가능
  - 맛 항목과 별도로 종합 점수(별 1~5) 입력
  - 음식별로 개인 메모를 남길 수 있음
    - 메모는 그룹 전체 공개
  - 음식의 점수는 사용자의 점수 평균로 계산
    - 음식 점수 = 종합 점수 평균, 맛 항목은 항목별 평균
    - 평가하지 않은 항목은 평균 계산에서 제외
  - 1인 1평가, 다시 평가하면 덮어씀
- [ ] 음식 종류는 완제품, 밀키트, 배달 가게 메뉴
  - 배달 가게 메뉴는 가게명 입력
- [ ] 사용자는 각각 계정으로 로그인
  - 구글 인증으로 로그인
  - 그룹은 1개만 운영
  - 초대 링크로만 가입 가능, 첫 가입자가 관리자
    - 초대 링크는 7일 유효·1회용
    - 관리자 이메일을 지정해 다른 사람이 먼저 관리자가 되는 것 방지
- [ ] 개별 음식을 묶어서 비교하는 기능
  - 예를 들면 '고기 만두 비교' 처럼 특정 주제로 여러 음식을 동시에 비교 가능
  - 이미 있는 음식이면 기존 평점을 가져오고, 새로운 음식을 추가할 수도 있음
  - 음식의 점수는 묶음 비교에서 수정해도 개별 점수도 수정됨
- [ ] 음식은 다양한 태그로 관리 가능
  - ex) 국/탕, 반찬, 음료, 주류, 아이스크림 등
- [ ] 최대한 쉽게 음식 정보(사진포함)을 입력할 수 있어야 함
  - 쿠팡, 네이버, 컬리 등 인터넷 사이트에서 음식 대표 이미지 및 정보 가져오기
    - 상품 URL 붙여넣기 시 제품명·대표 이미지·가격·브랜드 자동 추출(컬리·11번가 등), 실패 시 직접 입력
    - 상품명 검색(API) 입력: 연결부만 구현, API 키 발급 후 연동
  - 음식별로 사진을 최대 5개씩 첨부 가능
    - 음식당 전체 5장(사용자별 아님)
- [ ] 업데이트 내역 화면
  - 버전·날짜·변경 사항 목록

### 하지 않을 것

- 사이트 내에서 AI API를 사용한 분석

## ④ 개발 참고사항

### 참고사항

- 예상 사용자는 10인 이하

## ⑤ 환경

- **형태**: 웹 앱(동적 웹페이지)
- **실행 환경**: 인터넷 공개
- **주 사용 기기**: PC, 모바일, 태블릿
- **오프라인 동작**: 불필요

## ⑦ 디자인

- **분위기 키워드**: 파스텔, 귀여움, 레트로
- **라이트/다크**: 둘 다 지원
- **UI 라이브러리**: shadcn/ui + Tailwind CSS
- **접근성**: 글자 크기 조절, 충분한 대비

## ⑧ 데이터

- **저장 장소**: 클라우드 DB
- **데이터 출처**: 직접 입력, 웹 크롤링
- **백업/내보내기**: 수동 내보내기(CSV·JSON) + D1 Time Travel(30일) + 주 1회 자동 백업(R2)
